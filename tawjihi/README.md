## 🚀 التشغيل (مرة وحدة بس)

### 1) انشر الصفحات على الإنترنت (GitHub Pages، مجاني)
1. على GitHub افتح المستودع ← **Settings** ← **Pages**
2. من **Source** اختار `Deploy from a branch`، واختار الفرع اللي فيه مجلد `tawjihi`، والمجلد `/ (root)` ← **Save**
3. بعد دقيقة بيصير عندك:
   - صفحة نورس: `https://<اسم-حسابك>.github.io/renas-birthday/tawjihi/`
   - صفحة الأب: `https://<اسم-حسابك>.github.io/renas-birthday/tawjihi/dad.html`

> ملاحظة: إذا المستودع خاص (private) ممكن GitHub Pages يطلب اشتراك مدفوع؛ وقتها خلّي المستودع public أو انشر المجلد على Netlify أو Vercel (اسحب المجلد وأفلته).

### 2) إشعارات الأب على كروم 🔔
- افتح صفحة الأب على كروم، واضغط **"تفعيل إشعارات المتصفح"** (بيوصلك إشعار والصفحة مفتوحة).
- عشان يوصل الإشعار **حتى والصفحة مسكّرة**: اضغط **"اشترك بالإشعارات"**، وبتفتح صفحة ntfy، اضغط **Subscribe** واسمح بالإشعارات. أو نزّل تطبيق **ntfy** على الموبايل واشترك بنفس القناة:
  `nawras-tj-24691bb0e278`

### 3) قاعدة البيانات Firebase (موصى فيها جداً، 5 دقائق)
بدون Firebase، النظام بيشتغل فوراً وبيزامن عن طريق ntfy.sh، **بس** ntfy بيحتفظ بآخر نسخة لمدة 12 ساعة بس. يعني إذا صفحة الأب انفتحت على جهاز جديد بعد ما نورس غاب 12 ساعة بدون تسجيل، رح تكون فاضية لحد ما يسجّل مرة ثانية (الجهاز اللي انفتحت عليه قبل بيضل محتفظ بنسخته). مع Firebase كل شيء بينحفظ للأبد وبيتحدث لحظياً:

1. افتح https://console.firebase.google.com ← **Add project** (أي اسم، وطفّي Analytics)
2. من القائمة: **Build ← Realtime Database ← Create Database** ← اختار أقرب موقع ← **Start in test mode**
3. من تبويب **Rules** حط هاي القواعد واضغط **Publish**:
   ```json
   {
     "rules": {
       "tawjihi": {
         "nawras-tj-24691bb0e278": { ".read": true, ".write": true }
       }
     }
   }
   ```
4. من ⚙️ **Project settings ← General ← Your apps** اضغط على أيقونة الويب `</>`، سجّل التطبيق، وانسخ قيم `firebaseConfig`
5. افتح `config.js` وحط القيم مكان `firebase: null`، مثلاً:
   ```js
   firebase: {
     apiKey: "AIza...",
     authDomain: "xxx.firebaseapp.com",
     databaseURL: "https://xxx-default-rtdb.firebaseio.com",
     projectId: "xxx",
     appId: "1:...:web:..."
   },
   ```
6. احفظ وارفع الملف. خلص! رح يصير مكتوب فوق بالصفحتين: **"متصل · قاعدة البيانات"** 🎉
